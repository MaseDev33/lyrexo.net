# lyrexo.net website

A small, responsive static personal website.

## Files
- `index.html` - complete website, styles, and theme toggle
- `favicon.svg` - site icon

## Deploy
Upload both files to the document root of your web server. The site does not require a build step, framework, database, or server-side runtime.

The contact links use `mailto:me@lyrexo.net`.
The theme preference is saved in the visitor's browser.
